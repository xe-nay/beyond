# Muscle map artwork

`male.json` and `female.json` are the front and back muscle panels of
[Open-Muscle-Map](https://github.com/PerspicaciousGuy/Open-Muscle-Map) (commit `df85e6c`), MIT licence
(see `LICENSE`), compacted to what the app draws: each panel's view (`f` front, `r` rear), transform,
paths, muscle id, subregion, side and bounds. The panels are schematic regions, not exact anatomy.
